Privacy & Security Disclosure: Mini Analytics does not use invasive browser fingerprinting, track across third-party websites, or store raw IP addresses in event logs. IP addresses are keyed and salted using server-side HMAC-SHA256 with key versioning. Visitor identities represent pseudonymous browser session cookies (_ma_vid) set with HttpOnly and SameSite=Lax. Rotating the HMAC secret changes the deduplication key for IP counts. In jurisdictions subject to GDPR/CCPA, HMAC-pseudonymized IP data may still be classified as pseudonymous personal data.
